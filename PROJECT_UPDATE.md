# AI-Powered Job Portal

## Project Update

This project provides a platform connecting job seekers and recruiters.

### Current Features

- Candidate registration and authentication
- Recruiter registration and authentication
- Job creation and management
- Job search and job details
- Job application system
- Candidate profile management
- Resume upload
- Recruiter applicant management
- MongoDB database integration
- REST API using Node.js and Express
- React-based frontend

## Technology Stack

- React
- Node.js
- Express.js
- MongoDB
- Mongoose
- JavaScript
- Vite

## Development Status

The project is under active development with additional AI-powered recruitment features planned.
